# WebAR-каталог

Статический WebAR-проект на MindAR.js и A-Frame. Сборка, npm и серверная часть не требуются.

Используется существующий `targets (1).mind` без изменения содержимого. Пробел в URL закодирован как `%20`. Сохраняйте это имя при публикации.

Видео вписывается в размеры страницы с сохранением пропорций. До начала воспроизведения плоскость скрыта, камера остаётся видимой. При потере target видео останавливается и сбрасывается в начало; при смене target остальные видео останавливаются. Сохранены muted, playsinline и повторный запуск касанием для iPhone.

## Локальная проверка

Запустите `python -m http.server 8000` из папки проекта и откройте `http://localhost:8000`. Для проверки на телефоне нужен HTTPS с доверенным сертификатом: обычный HTTP по IP компьютера не подходит для доступа к камере. Требуется интернет для загрузки A-Frame и MindAR.

На Android Chrome и iPhone Safari проверьте все 10 страниц: соответствие видео, отсутствие растяжения, видимость камеры, отсутствие чёрной плоскости до загрузки видео и VR-кнопки. Уведите страницу из кадра и верните: видео должно начаться с нуля. Быстро переключайте страницы и покажите две сразу: играть должно только одно видео. Проверьте запуск касанием, если браузер блокирует autoplay.

## Публикация на GitHub Pages

1. Загрузите файлы проекта в корень репозитория GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
5. После завершения публикации откройте выданную GitHub HTTPS-ссылку и разрешите доступ к камере.

Все ресурсы подключены относительными путями, поэтому проект работает из GitHub Pages без дополнительной настройки.

Для обновления публикации замените `index.html`, `README.md`, загрузите финальный `targets (1).mind` и все 10 MP4 из таблицы с точными именами в ту же папку. Сохраните `.nojekyll`. Изображения JPG во время работы сайта не загружаются; менять их не требуется.
